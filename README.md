# Perkura

Статичная вёрстка сайта студии интерьерного дизайна **Perkura**.

## О проекте

Сайт-презентация студии: услуги, портфолио проектов, информация о команде и контакты.

> Раздел в работе — описание будет дополнено.

## Технологии

- HTML5
- CSS3
- JavaScript

## Структура

```
perkura/
├── index.html      # Главная страница
├── styles.css      # Стили
├── script.js       # Скрипты
└── assets/         # Изображения
```

## Локальный запуск

Открыть `index.html` в браузере или поднять локальный сервер:

```bash
python -m http.server 8000
```

Затем перейти на http://localhost:8000

## Деплой

Сайт публикуется через GitHub Pages из ветки `main` (корень репозитория).
